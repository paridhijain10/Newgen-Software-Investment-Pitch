# Newgen Software Investment Pitch

## Overview

Equity research and valuation project on Newgen Software Technologies Ltd., focused on financial performance, recurring revenue growth, SaaS expansion, competitive positioning, and valuation.

## Project Components

- 5-year historical financial analysis
- 5-year DCF valuation through FY31E
- Trading comparables using P/E and EV/EBITDA
- Industry and competitive analysis
- Recurring revenue and SaaS growth analysis
- Catalyst and risk assessment
- 10-slide investment pitch deck

## Key Analysis

| Metric | Value |
|---|---:|
| FY26 Revenue | ₹1,574 Cr |
| FY26 EBITDA | ₹406 Cr |
| FY26 Annuity Revenue | ₹968 Cr |
| FY26 SaaS Growth | +36% |
| FY22–FY26 Revenue CAGR | 19.2% |
| DCF Implied Share Value | ₹384 |
| EV/EBITDA Implied Share Value | ₹678 |
| P/E Implied Share Value | ₹682 |
